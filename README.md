How It Works
The user enters:
1. Property area in square feet
2. Number of bedrooms
3. Number of bathrooms
4. Property location
The frontend sends these values to the Flask API:
POST /api/predict_home_price

The Flask server loads the trained Linear Regression model and generates a price prediction.
The location dropdown is populated through:
GET /api/get_location_names

The API returns the available locations from the trained model's feature data.
API Endpoints
Get Locations
GET /api/get_location_names

Example response:
{
  "locations": [
    "1st block jayanagar",
    "1st phase jp nagar",
    "whitefield",
    "yelahanka"
  ]
}

Predict House Price
POST /api/predict_home_price

Parameters:
Parameter	Description
total_sqft	Property area in square feet
bhk	Number of bedrooms
bath	Number of bathrooms
location	Bangalore property location


Example:
curl -X POST http://127.0.0.1:5000/predict_home_price \
  -d "total_sqft=1000" \
  -d "location=1st phase jp nagar" \
  -d "bhk=2" \
  -d "bath=2"

Example response:
{
  "estimated_price": 83.5
}

The predicted price is expressed in lakhs of Indian rupees.
Running Locally
1. Clone the repository
git clone https://github.com/YOUR_USERNAME/bangalore-home-price-prediction.git
cd bangalore-home-price-prediction

2. Create a virtual environment
python3 -m venv venv
source venv/bin/activate

3. Install dependencies
pip install -r server/requirements.txt

4. Start Flask
cd server
python server.py

The Flask API will run on:
http://127.0.0.1:5000

5. Open the frontend
Open:
client/app.html

For local development, the frontend API URLs may need to be configured depending on whether Nginx is being used.
AWS Deployment
The application is deployed on an AWS EC2 Ubuntu instance.
Deployment architecture:
Internet
   |
   v
AWS EC2
   |
   +-- Nginx :80
   |
   +-- Flask :5000
          |
          +-- Linear Regression Model

Nginx serves the frontend and forwards /api/ requests to the Flask application.
Flask is managed using systemd, allowing the API to automatically start after an EC2 reboot.
Deployment Configuration
The Flask application runs as:
/home/ubuntu/code/BHP/venv310/bin/python

The systemd service is:
bhp.service

Check the service with:
sudo systemctl status bhp

Enable automatic startup:
sudo systemctl enable bhp

Machine Learning Model
The application uses a Linear Regression model trained on Bangalore house-price data.
The trained model is stored as:
server/artifacts/banglore_home_prices_model.pickle

The feature/location information is stored in:
server/artifacts/columns.json

The training workflow and experimentation are documented in:
model/bhp.ipynb
